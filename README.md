# genma-pc · 幻魔鬼武者 PC 移植运行层

《幻魔鬼武者》Xbox 日版的非官方 Windows 原生移植运行层，基于 [Spark198rus/black-pc](https://github.com/Spark198rus/black-pc) 开发，提供启动器、输入增强及图形修复。

**版本：v0.2.6**  
**整理日期：2026-10-17**

本项目公开移植运行层与相关工具的源码及制作方法，供有兴趣的开发者自行编译、研究和继续完善。

## 项目范围

- 公开内容为 PC 移植运行层与相关工具，不含 CAPCOM 原始游戏开发源码或游戏资源。
- 运行需要自行准备支持版本的完整 Xbox 游戏文件。
- 源码包不包含游戏本体、ISO、BIOS 或个人存档。
- 游戏内容本身不在本项目代码许可的授权范围内。

## 功能

- 针对《幻魔鬼武者》的图形、音频、手柄与键盘输入适配
- 启动器
- 按镜头方向移动的左摇杆操作
- 攻击软锁定
- 架势四向闪避

## v0.2.6 修复

本版本包含以下已定位问题的修复：

- 背景切换延迟
- 左右侧闪方向异常
- 争夺绿魂时的贴图上传掉帧
- 使用鬼战术后角色只能移动
- 人物阴影缺失

## 运行方式

项目加载原 Xbox 游戏的 XBE，直接执行其中的 x86 游戏代码，并通过 HLE（高层模拟）适配系统、图形与音频接口。

项目未使用 xboxrecomp 将整个游戏转换为 C 代码。

## 编译与运行准备

使用源码前，请准备：

1. Windows 运行环境。
2. 项目支持版本的完整 Xbox 游戏文件。
3. 对应版本编译说明要求的开发环境与依赖。

下载源码后，需要先完成编译，再按对应说明配置游戏文件。具体编译步骤、回归测试与 Bug 排查方法，请参阅对应版本的项目文档。

## 开发与验证

开发过程中使用了 Claude、ChatGPT 与 Codex 辅助编写代码、分析问题及整理文档，并结合实际试玩和玩家反馈逐步修正问题。

目前已进行代表场景验证与专项回归，但尚未完成全部游戏流程和所有硬件环境的验证。现有修复不代表所有场景均已无误，仍需要更多测试与反馈。
