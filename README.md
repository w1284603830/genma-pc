【标题】

【长版：动态／专栏／视频简介】
这次把《幻魔鬼武者》PC 移植项目 genma-pc 的源码和制作方法整理公开，想让有兴趣的朋友能够自己编译、研究，也欢迎继续完善。

项目以 Spark198rus 的 black-pc 为基础，针对幻魔鬼武者适配了图形、音频、手柄和键盘输入，加入启动器、按镜头方向移动的左摇杆、攻击软锁定及架势四向闪避。开发使用 Claude 与 Codex 辅助，结合实际试玩和玩家反馈逐步修正。

当前源码为 v0.2.6，包含背景切换延迟、左右侧闪方向、争夺绿魂时的贴图上传掉帧、鬼战术后只能移动，以及人物阴影缺失等已定位问题的修复。包内也放了编译说明、回归测试和 Bug 排查方法，方便了解“为什么这样改”，而不只是拿到一个可执行文件。

公开的是 PC 移植运行层与相关工具，不是 CAPCOM 当年的游戏开发源码。运行仍需自行准备支持版本的 Xbox 游戏文件；源码包不含游戏本体、ISO、BIOS 或个人存档。

代码沿用 GPL-2.0-or-later，感谢 black-pc 和相关开源社区。项目仍待更多场景与硬件验证，欢迎带上具体位置、操作步骤、配置及日志反馈。源码与编译说明见本帖附件。

【常见问题】
1. 这是完整游戏源码吗？
   是本项目的移植层与工具源码，不含 CAPCOM 原始游戏源码或资源。
2. 采用什么方法？
   加载原 Xbox XBE，直接执行 x86 游戏代码，通过 HLE 适配系统、图形和音频；未使用 xboxrecomp 将整个游戏转成 C。
3. 下载源码就能玩了吗？
   需要编译，再自行放入支持版本的完整游戏文件。源码包不含个人存档。
4. 能修改或继续开发吗？
   可以，按 GPL-2.0-or-later 使用、修改和再发布，保留相应许可与源码。游戏内容本身不在此授权范围。
5. 已经完全没有 Bug 了吗？
   已有代表场景及专项回归，未完成全部流程和所有硬件验证。请提供可复现步骤帮助改进。
